# 権限テスト計画

この文書は `sdd_spec.md` の権限仕様を確認するためのテスト計画です。メンター、メンバー、ゲストで許可される操作と拒否される操作を明確にし、リリース前の手動テストまたは自動テストに使います。

## 1. テストアカウント

| 種別 | 条件 |
|---|---|
| メンター | 有効なmentorロール、初回パスワード変更済み |
| メンバー | 有効なmemberロール、初回パスワード変更済み、ranking_visible=true |
| ランキング非表示メンバー | 有効なmemberロール、ranking_visible=false |
| 無効メンバー | is_active=false |
| ゲスト | 未ログイン状態 |

## 2. 認証

| ケース | 操作者 | 期待結果 |
|---|---|---|
| 正しいIDとパスワードでログイン | メンター | メンターダッシュボードへ遷移する |
| 正しいIDとパスワードでログイン | メンバー | メンバーホームへ遷移する |
| 誤ったパスワードでログイン | 全ユーザー | `IDまたはパスワードが違います` を表示する |
| 無効アカウントでログイン | 無効メンバー | ログイン不可になる |
| 初回パスワード未変更でログイン | メンターまたはメンバー | パスワード変更へ誘導する |

## 3. 拒否時の共通期待結果

権限不足で拒否される操作は、APIではHTTP 403 Forbiddenと `{"error":"forbidden","message":"権限がありません"}` を返し、対象データを変更しない。UIでは管理画面や対象機能への遷移を止め、ログイン済みの場合は `権限がありません` を表示し、未ログインの場合はログイン画面へ戻す。

## 4. メンター権限

| 操作 | 期待結果 |
|---|---|
| メンバーアカウント作成 | 成功する |
| メンターアカウント作成 | 成功する |
| 仮パスワード表示 | 作成直後に一度だけ表示される |
| 全メンバーのログ閲覧 | 成功する |
| 開発ログ承認 | EXP、ランキング、ステータスへ反映される |
| 修正承認 | 修正後の値でEXP、ランキング、ステータスへ反映される |
| 却下 | EXP、ランキング、ステータスへ反映されない |
| 実績承認 | 報酬付与の対象になる |
| ボスHP調整 | 成功し、監査ログに残る |
| 不適切URL非公開 | 成功し、監査ログに残る |

## 5. メンバー権限

| 操作 | 期待結果 |
|---|---|
| 自分の開発ログ作成 | 成功する |
| 自分の開発ログ編集 | 許可範囲内で成功する |
| 他メンバーの開発ログ編集 | 403 Forbiddenと `権限がありません` を返し、変更されない |
| 全メンバーのログ閲覧 | 403 Forbiddenと `権限がありません` を返す |
| ログ承認 | 403 Forbiddenと `権限がありません` を返し、承認状態は変わらない |
| 実績申請 | 成功する |
| 実績承認 | 403 Forbiddenと `権限がありません` を返し、報酬は付与されない |
| ボスHP調整 | 403 Forbiddenと `権限がありません` を返し、HPは変わらない |
| ボス戦参加 | 成功する |
| ランキング閲覧 | 成功する |
| プロダクトURL登録 | 成功する |
| 不適切URL非公開 | 403 Forbiddenと `権限がありません` を返し、公開状態は変わらない |

## 6. ゲスト権限

| 操作 | 期待結果 |
|---|---|
| ログイン画面表示 | 成功する |
| メンバーホーム表示 | ログイン画面へ遷移し、メンバーデータは返さない |
| メンターダッシュボード表示 | ログイン画面へ遷移し、管理データは返さない |
| 開発ログ作成 | 401 Unauthorizedまたはログイン画面へ遷移し、作成されない |
| ランキング閲覧 | 401 Unauthorizedまたはログイン画面へ遷移し、ランキングデータは返さない |
| ボス戦参加 | 401 Unauthorizedまたはログイン画面へ遷移し、参加状態は作成されない |
| プロダクトURL登録 | 401 Unauthorizedまたはログイン画面へ遷移し、URLは保存されない |

## 7. ランキング表示制御

| ケース | 期待結果 |
|---|---|
| ranking_visible=trueのメンバー | ランキングにニックネームのみ表示される |
| ranking_visible=falseのメンバー | ランキングに表示されない |
| 本名データ入力 | 入力欄または保存対象として存在しない |
| 開発内容ランキング | 作成されていない |

## 8. 承認反映制御

| ケース | 期待結果 |
|---|---|
| 承認待ちログ | 仮成長のみ表示され、正式EXPへ反映されない |
| 承認済みログ | EXP、ランキング、ステータス、ボス戦力へ反映される |
| 却下ログ | EXP、ランキング、ステータス、ボス戦力へ反映されない |
| 承認済みログの再承認 | 二重反映されない |
| 未完了セッション | 承認されるまでEXPとランキングに反映されない |
| 不審ログ | 自動却下されず、メンター確認対象になる |

## 9. 監査ログ確認

次の操作後に、操作者、対象、変更前、変更後、操作日時が記録されることを確認する。

- アカウント作成
- パスワード変更
- 開発ログ編集
- 承認
- 修正承認
- 却下
- 実績承認
- ボスHP変更
- URL非公開化

## 10. 合格条件

- 権限表で許可された操作だけが成功する。
- 拒否される操作は、データ変更を行わず明確に失敗する。
- メンバーは他人の非公開情報や管理操作へ到達できない。
- ゲストはログイン以外の操作へ到達できない。
- メンター操作は監査ログへ記録される。
