# 権限テスト計画

この文書は `sdd_spec.md` の権限仕様を確認するためのテスト計画です。メンター、メンバー、ゲストで許可される操作と拒否される操作を明確にし、リリース前の手動テストまたは自動テストに使います。

## 1. テストアカウント

| 種別 | 条件 |
|---|---|
| メンター | 有効なmentorロール、初回パスワード変更済み |
| メンバー | 有効なmemberロール、初回パスワード変更済み、ランキング表示ON |
| ランキング非表示メンバー | 有効なmemberロール、ranking_visible=false |
| 無効メンバー | is_active=false |
| ゲスト | 未ログイン状態 |

## 2. 認証

| ケース | 操作者 | 期待結果 |
|---|---|---|
| 正しいIDとパスワードでログイン | メンター | メンターダッシュボードへ遷移する |
| 正しいIDとパスワードでログイン | メンバー | メンバーホームへ遷移する |
| 誤ったパスワードでログイン | 全ユーザー | `IDまたはパスワードが違います` を表示する |
| 無効アカウントでログイン | 無効メンバー | ログイン不可になる |
| 初回パスワード未変更でログイン | メンターまたはメンバー | パスワード変更へ誘導する |

## 3. メンター権限

| 操作 | 期待結果 |
|---|---|
| メンバーアカウント作成 | 成功する |
| メンターアカウント作成 | 成功する |
| 仮パスワード表示 | 作成直後に一度だけ表示される |
| 全メンバーのログ閲覧 | 成功する |
| 開発ログ承認 | EXP、ランキング、ステータスへ反映される |
| 修正承認 | 修正後の値でEXP、ランキング、ステータスへ反映される |
| 却下 | EXP、ランキング、ステータスへ反映されない |
| 実績承認 | 報酬付与の対象になる |
| ボスHP調整 | 成功し、監査ログに残る |
| 不適切URL非公開 | 成功し、監査ログに残る |

## 4. メンバー権限

| 操作 | 期待結果 |
|---|---|
| 自分の開発ログ作成 | 成功する |
| 自分の開発ログ編集 | 許可範囲内で成功する |
| 他メンバーの開発ログ編集 | 拒否される |
| 全メンバーのログ閲覧 | 拒否される |
| ログ承認 | 拒否される |
| 実績申請 | 成功する |
| 実績承認 | 拒否される |
| ボスHP調整 | 拒否される |
| ボス戦参加 | 成功する |
| ランキング閲覧 | 成功する |
| プロダクトURL登録 | 成功する |
| 不適切URL非公開 | 拒否される |

## 5. ゲスト権限

| 操作 | 期待結果 |
|---|---|
| ログイン画面表示 | 成功する |
| メンバーホーム表示 | 拒否またはログイン画面へ遷移する |
| メンターダッシュボード表示 | 拒否またはログイン画面へ遷移する |
| 開発ログ作成 | 拒否される |
| ランキング閲覧 | 拒否される |
| ボス戦参加 | 拒否される |
| プロダクトURL登録 | 拒否される |

## 6. ランキング表示制御

| ケース | 期待結果 |
|---|---|
| ranking_visible=trueのメンバー | ランキングにニックネームのみ表示される |
| ranking_visible=falseのメンバー | ランキングに表示されない |
| 本名データ入力 | 入力欄または保存対象として存在しない |
| 開発内容ランキング | 作成されていない |

## 7. 承認反映制御

| ケース | 期待結果 |
|---|---|
| 承認待ちログ | 仮成長のみ表示され、正式EXPへ反映されない |
| 承認済みログ | EXP、ランキング、ステータス、ボス戦力へ反映される |
| 却下ログ | EXP、ランキング、ステータス、ボス戦力へ反映されない |
| 承認済みログの再承認 | 二重反映されない |
| 未完了セッション | 承認されるまでEXPとランキングに反映されない |
| 不審ログ | 自動却下されず、メンター確認対象になる |

## 8. 監査ログ確認

次の操作後に、操作者、対象、変更前、変更後、操作日時が記録されることを確認する。

- アカウント作成
- パスワード変更
- 開発ログ編集
- 承認
- 修正承認
- 却下
- 実績承認
- ボスHP変更
- URL非公開化

## 9. 合格条件

- 権限表で許可された操作だけが成功する。
- 拒否される操作は、データ変更を行わず明確に失敗する。
- メンバーは他人の非公開情報や管理操作へ到達できない。
- ゲストはログイン以外の操作へ到達できない。
- メンター操作は監査ログへ記録される。
