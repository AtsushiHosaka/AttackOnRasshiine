## Notes

- The `.br` WebGL artifacts must be served with `Content-Encoding: br`.
- The wasm payload must be served as `application/wasm`.
- `supabase-config.json` is generated by the WebFront build script. If Supabase env vars are missing, it intentionally writes a disabled config so the Unity app can fall back cleanly.
